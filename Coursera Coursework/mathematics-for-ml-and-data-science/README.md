# Mathematics for Machine Learning and Data Science

Labs and assignments from the Coursera specialization "Mathematics for Machine Learning and Data Science" by DeepLearning.AI.

## About the Specialization

This specialization covers the foundational math required for machine learning and data science: linear algebra, calculus, probability, and statistics. The hands-on labs use Python and NumPy to implement the concepts.

## Contents

### Course 1: Linear Algebra for Machine Learning and Data Science

**Week 1: Systems of Linear Equations**
- `C1_W1_Lab_1_introduction_to_numpy_arrays.ipynb` - Introduction to NumPy arrays
- `C1_W1_Lab_2_solving_linear_systems_2_variables.ipynb` - Solving linear systems with 2 variables

**Week 2: Solving Systems of Linear Equations**
- `C1_W2_Lab_1_solving_linear_systems_3_variables.ipynb` - Solving systems with 3 variables

- `C1_W3_Lab_3_linear_transformations.ipynb` - Linear transformations
- `C1_W3_Assignment.ipynb` - Week 3 graded assignment

**Week 4: Determinants and Eigenvectors**
- `C1_W4_Assignment.ipynb` - Week 4 graded assignment
