# Complete Python Developer Course

Projects and exercises from the Zero to Mastery Complete Python Developer course.

## Projects

### AutomationAndTestingWithSeleniumProject
Browser automation using Selenium WebDriver for web scraping and automated testing.

### EmailsProject
Email sending with Python's smtplib, including HTML email templates.

### imageProcessingProject
Image manipulation using the Pillow library. Includes JPEG to PNG conversion and image transformations.

### IntroToWebDevelopment_VSCode
Introduction to web development with Flask, including HTML templates and static files.

### ML and Data Science
Machine learning project using pandas for data analysis. Includes a Jupyter notebook for soccer data analysis.

### Modules_Practice_Project
Practice with Python modules, packages, and imports.

### PasswordCheckerProject
Password strength checker that uses the Have I Been Pwned API to check for compromised passwords.

### PDFsProject
PDF manipulation with PyPDF2 - merging, watermarking, and rotating PDF files.

### PortifolioWebsiteProject
Flask-based portfolio website with contact form functionality.

### SMSwithPythonProject
SMS and notifications using Twilio API and ntfy service.

### TranslatorProject
Text translation using translation APIs.

### WebScrapingProject
Web scraping with BeautifulSoup and requests library.

## Setup

Most projects require a virtual environment:

```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt  # If requirements.txt exists in the project
```

## Notes

- Some projects require API keys (Twilio, translation services). Add your own credentials where indicated.
- The Selenium project requires ChromeDriver installed separately and matching your Chrome version.
- The ML project uses Jupyter notebooks - run with `jupyter notebook`.
