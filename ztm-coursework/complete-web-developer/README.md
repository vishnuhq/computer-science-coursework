### Robot Animation (Exercise 1)

A CSS animation exercise featuring a robot character built with HTML and CSS.

**Files:**
- `index.html` - HTML structure for the robot
- `style.css` - CSS styling and animations

**Features:**
- CSS animations and keyframes
- CSS transforms
- HTML/CSS positioning

**To View:**
Open `index.html` in any web browser.
